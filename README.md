# AED 使用平台

一个面向公众的 AED 急救服务网站，将 AED 地图查找、设备认识、使用教学和心脏健康知识整合到统一的应用式界面中。

## 在线访问

<https://2913800552.github.io/aed-platform/>

> 公开代码仓库不包含项目图片素材；完整视觉资源保留在项目私有备份中，线上网站仍提供完整体验。

## 主要功能

- **查找 AED**：连接现有 AED 地图，支持设备位置查找与导航。
- **认识 AED**：通过可交互设备模型了解屏幕、电源键、电极片和电击键。
- **使用说明**：用五个独立步骤讲解确认状态、呼叫求助、胸外按压、开机贴片以及分析与电击。
- **健康生活**：提供远离烟草、均衡饮食、规律活动和关注健康指标等专题内容。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:3000/`。

## 构建检查

```bash
npm run build
```

## 重要说明

本项目用于公众急救知识展示，不能替代正规急救培训、专业医疗判断或现场急救调度指引。遇到紧急情况请立即拨打 120，并遵循调度员及现场 AED 设备的语音提示。
